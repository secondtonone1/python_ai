## 3. 核心教学点（建议课堂强调）

1. **AI 引擎可插拔**：`BotEngine` 抽象 + `RuleEngine` 实现 + 引擎纯函数化（不碰库、好测试）。
   提问学生："接入真实大模型要改哪些文件？"（答案：只新增一个 LLMEngine 类 + 改一行装配代码）
2. **事件循环里绝不跑阻塞代码**：`handle_chat` 把限流/入库/引擎计算整体投给线程池，
   事件循环只负责 50ms 节奏的流式推送 —— 这是 88 课"协程+线程池"模式的 Web 化应用。
3. **同步端点 vs 异步端点**：`def` 端点（FastAPI 自动线程池）与 `async def` 端点（事件循环）的区别，
   以及什么时候该用哪种。
4. **WebSocket 与 TCP 的知识迁移**：长连接、心跳（ping/pong）、断线重连、粘包（WebSocket 自带分帧）——
   把 84-89 课的概念在 Web 场景重新对应。
5. **安全三板斧**：参数化 SQL（防注入）、SHA256 加盐（密码存储）、textContent 渲染（防 XSS）。
6. **快速失败与优雅降级**：连接池启动初始化失败仅告警不退出（Web 服务让 DB 恢复后自愈），
   数据接口在 DB 不可用时统一返回 500 JSON 而不是 HTML 错误页。

## 4. 学生扩展作业（由易到难）

1. 【入门】在知识库中新增 3 条与"课程"相关的知识，并在聊天页验证机器人能命中。
2. 【入门】把流式输出速度调快/调慢（config.json 的 bot.stream_chunk_delay），观察打字机效果变化。
3. 【进阶】机器人增加"敏感词"过滤：检测到敏感词时回复固定话术（新增一个过滤器类）。
4. 【进阶】客服工作台增加"已关闭会话"的恢复能力：重新打开已关闭的会话继续对话。
5. 【进阶】给 /api/staff/sessions 列表增加"最后一条消息预览"字段（SQL 子查询）。
6. 【挑战】用 Flask 重写 api 层（service/dao 完全不动），对比 FastAPI 与 Flask 的开发体验。
7. 【挑战】给 RuleEngine 增加"同义词"支持：配置同义词表（如"多少钱"="价格"="费用"），匹配时归一化。
8. 【前瞻】思考：接入真实大模型（如 DeepSeek API）时，BotReply、流式输出、追问状态机
   哪些可以保留、哪些需要重写？（为 LangChain 阶段埋伏笔）
